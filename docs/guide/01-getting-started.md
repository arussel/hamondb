# Getting started

Hamon is an in-memory reactive store. You declare your data as plain Rust
structs; Hamon handles storage, primary keys, derived values, change notification
and secondary indexes.

This chapter walks through installing the crate, defining a table, and the
five core CRUD operations: `insert`, `get`, `update`, `replace`, `delete`.

## Install

Add the dependency in `Cargo.toml`:

```toml
[dependencies]
hamondb = { git = "https://github.com/arussel/hamondb" }
```

Hamon is not yet on crates.io.

## A table in three pieces

A table is a `#[derive(Clone, Table)]` struct with exactly one field marked
`#[primary_key]`. The derive generates one typed [`Column`] handle per field
(as a `SHOUTY_SNAKE_CASE` associated constant) and wires the type into the
builder.

```rust
use hamondb::{HamonBuilder, Table};

#[derive(Clone, Table)]
struct Order {
    #[primary_key]
    id: u64,
    qty: i64,
    price_cents: i64,
}
```

That's enough to register the table and start writing data:

```rust
# use hamondb::{HamonBuilder, Table};
# #[derive(Clone, Table)]
# struct Order { #[primary_key] id: u64, qty: i64, price_cents: i64 }
let mut builder = HamonBuilder::new();
builder.register_table::<Order>();
let (db, _shutdown) = builder.build();

db.insert(Order { id: 1, qty: 10, price_cents: 500 }).unwrap();
assert_eq!(db.len::<Order>(), 1);
```

`build` returns a pair `(Hamon, HamonShutdown)`. Hold the `HamonShutdown` for
the lifetime of the database; dropping it signals background threads to stop
and joins them. Dropping the `Hamon` alone does *not* shut anything down.

## Reading

`get` returns a clone of the row — the read lock is released before the call
returns, so the value you get back is a snapshot, not a live view:

```rust
# use hamondb::{HamonBuilder, Table};
# #[derive(Clone, Table)]
# struct Order { #[primary_key] id: u64, qty: i64, price_cents: i64 }
# let mut builder = HamonBuilder::new();
# builder.register_table::<Order>();
# let (db, _shutdown) = builder.build();
# db.insert(Order { id: 1, qty: 10, price_cents: 500 }).unwrap();
let order = db.get::<Order>(&1).unwrap();
assert_eq!(order.qty, 10);
```

`get` is a point lookup by primary key. For a full-table scan, use
[`for_each`](#iterating):

```rust
# use hamondb::{HamonBuilder, Table};
# #[derive(Clone, Table)]
# struct Order { #[primary_key] id: u64, qty: i64, price_cents: i64 }
# let mut builder = HamonBuilder::new();
# builder.register_table::<Order>();
# let (db, _shutdown) = builder.build();
# db.insert(Order { id: 1, qty: 10, price_cents: 500 }).unwrap();
let mut total: i64 = 0;
db.for_each::<Order>(|order| {
    total += order.qty * order.price_cents;
});
assert_eq!(total, 5_000);
```

`for_each` holds the per-row read lock while your closure runs for that row —
don't do slow work inside it.

## Writing

Hamon distinguishes four write operations:

| Operation  | Semantics                                   | On missing key          |
|------------|---------------------------------------------|-------------------------|
| `insert`   | Fails if the key already exists             | *(insert is the create)*|
| `replace`  | Overwrites the full row                     | `Err(KeyNotFound)`      |
| `update`   | Partial update by typed column handle       | `Err(KeyNotFound)`      |
| `upsert`   | Insert or replace in one call               | *(creates if absent)*   |

`update` takes a `(Column, value)` tuple for a single-field change:

```rust
# use hamondb::{HamonBuilder, Table};
# #[derive(Clone, Table)]
# struct Order { #[primary_key] id: u64, qty: i64, price_cents: i64 }
# let mut builder = HamonBuilder::new();
# builder.register_table::<Order>();
# let (db, _shutdown) = builder.build();
# db.insert(Order { id: 1, qty: 10, price_cents: 500 }).unwrap();
db.update::<Order>(&1, (Order::QTY, 42)).unwrap();
assert_eq!(db.get::<Order>(&1).unwrap().qty, 42);
```

The column constant `Order::QTY` is generated by the derive macro — see
[Typed columns](./04-typed-columns.md) for the rules on what the handle type
protects you from.

`insert` on an existing key is an error, not a silent overwrite:

```rust
# use hamondb::{HamonBuilder, Table};
# use hamondb::hamon_core::HamonError;
# #[derive(Clone, Table)]
# struct Order { #[primary_key] id: u64, qty: i64, price_cents: i64 }
# let mut builder = HamonBuilder::new();
# builder.register_table::<Order>();
# let (db, _shutdown) = builder.build();
# db.insert(Order { id: 1, qty: 10, price_cents: 500 }).unwrap();
let dup = db.insert(Order { id: 1, qty: 99, price_cents: 1 });
assert_eq!(dup, Err(HamonError::DuplicateKey));
```

Use `upsert` when "insert or replace" is what you actually want:

```rust
# use hamondb::{HamonBuilder, Table};
# #[derive(Clone, Table)]
# struct Order { #[primary_key] id: u64, qty: i64, price_cents: i64 }
# let mut builder = HamonBuilder::new();
# builder.register_table::<Order>();
# let (db, _shutdown) = builder.build();
db.upsert(Order { id: 1, qty: 10, price_cents: 500 }).unwrap();
db.upsert(Order { id: 1, qty: 20, price_cents: 500 }).unwrap(); // replaces
assert_eq!(db.get::<Order>(&1).unwrap().qty, 20);
```

`delete` removes by primary key:

```rust
# use hamondb::{HamonBuilder, Table};
# use hamondb::hamon_core::HamonError;
# #[derive(Clone, Table)]
# struct Order { #[primary_key] id: u64, qty: i64, price_cents: i64 }
# let mut builder = HamonBuilder::new();
# builder.register_table::<Order>();
# let (db, _shutdown) = builder.build();
# db.insert(Order { id: 1, qty: 10, price_cents: 500 }).unwrap();
db.delete::<Order>(&1).unwrap();
assert!(matches!(db.get::<Order>(&1), Err(HamonError::KeyNotFound)));
```
